# served TUI 设计规范

状态：已定型。新页面必须复用本规范的模板和组件；确需新交互时，先更新规范和验收案例。
本规范取代旧版常驻 tips 和多行完整快捷键栏。它约束管理界面和配置表单；attach 交给服务原始终端。

## 视觉规则

- 主列表和 Actions 在正文与页脚之间的原空行绘制一条弱化默认色横线，宽度与工作区一致；首次加载空白页不绘制。
- 默认无框。禁止装饰边框、阴影、渐变、emoji、图标字体和装饰动画。
- 背景沿用终端，不提供主题选择或彩色面板。标题和快捷键使用 ANSI 青色；标题加粗。
  普通列表项用反色表示选中，不显示箭头；管理列表每行固定留两格不着色的左侧空白。
  主列表高亮覆盖名称、间隔和状态文字，在文字末尾结束，不覆盖状态列的尾部空格；Actions 高亮覆盖动作名、间隔和快捷键。
  普通选中项使用终端默认前景／背景反色；取消选中后恢复语义颜色。
  Discard、丢弃修改的 Reload、Delete 和 Disable 未选中时红字，选中时 ANSI 红底黑字，覆盖原有高亮范围；NO_COLOR 下使用普通反色。
  高亮止于紧凑内容区，不延伸到工作区右边。
- running 和成功反馈使用 ANSI 绿色；starting/restarting、操作进度和断线警告使用黄色；
  failed、错误标题、未选中的危险动作名和危险操作后果说明使用红色。未保存修改的退出确认问题用黄色；stopped 和普通正文使用默认前景色。
- 路径、类型、计数、按键说明和阅读位置使用弱化的默认前景色。反馈携带明确语义，不根据消息文本猜测颜色。
- 非空 `NO_COLOR` 禁用显式颜色，保留文字、加粗和反色；状态不只依赖颜色区分。
  深色、浅色和无颜色环境都必须保持可读。
- 宽度至少 80 列时左右各留两格，40–79 列时各留一格；上下各留一行。
- 管理页（主屏、Actions、确认、历史列表）使用左对齐紧凑工作区，宽度最多 76 格。
  标题与计数相邻，如 `served · 3 services`；长标题先截断，保留计数。
- 页面顺序为标题、空行、正文、分隔行、合并页脚；主列表和 Actions 的分隔行使用横线，其余页面保留空行。主屏和 Actions 共用高度，按项目数与操作数中的较大值预留列表区域，下方空一行后绘制横线；项目更多时两页一起增高，到达窗口容量后滚动。小窗口不足以显示全部操作及留白时，先取消留白，再缩减列表容量，保留完整页脚。两页统一页脚换行阈值，空列表和加载状态也使用相同布局。其他管理页正文至少预留六行。提示栏跟随正文，不固定到窗口底部。
- 阅读页（日志、错误、崩溃提示）使用可用窗口宽高，页脚固定在阅读区域底部。
- 所有帮助页的按键提示跟随正文，空一行后与按键列左对齐；长帮助滚动时提示保留在可见正文下方，阅读位置在同一行右侧。
- 选择、状态、进度、成功反馈和断线不改变工作区尺寸；窗口或列表数量改变时重新计算。
- 管理页及普通阅读页的页脚信息靠左，按键组靠工作区右侧；所有页脚的按键使用青色，说明和左侧信息弱化。
  配置页按键组靠左；帮助及配置确认页的提示跟随正文。
  按键与说明间隔一格，按键组之间三格，左右信息至少间隔两格。
- 扣除按键组和两格间隔后，左侧至少可容纳 20 格时共用一行；否则使用相邻两行，
  上行信息、下行右对齐按键，不插入空行。切换只取决于窗口宽度和当前页按键组。
  正文高度、翻页和缩放后的滚动校正使用同一布局计算。
- 最小可用尺寸为 40×10。更小时只显示扩大窗口提示，Esc/q 和 Ctrl+C 仍可返回或退出。
- 名称和路径按字符单元宽度截断，保留完整字素。名称保留开头，路径保留末尾，用 `…` 标记。
  路径在 HOME 内时显示 `~`。完整名称、路径和类型可在操作页的 `?` 帮助中查看，PgUp/PgDn 滚动。

## 需求到模板的映射

| 需求 | 模板 | 允许的业务输入 |
| --- | --- | --- |
| 选择服务或历史记录 | 列表 | 标题、计数、行、选中项详情 |
| 对一个服务执行动作 | 操作页 | 服务信息、统一动作目录 |
| 阅读帮助或错误 | 阅读页 | 标题、完整正文 |
| 阅读输出历史 | 日志页 | 记录、逻辑行位置、加载状态 |
| 确认禁用 | 确认页 | 服务名称、后果说明、取消/禁用 |

页面骨架、列表选择、状态样式、文本截断和阅读滚动由共享组件处理。
业务页面不得自行选择颜色、边框或布局。动作目录统一生成菜单、快捷键和动作帮助。

## 主屏与操作

```text
 served · 3 services

   api         running
   worker      running
   scheduler   stopped




 ~/projects/api · enabled                 enter actions   ? help   esc/q quit
```

- 主屏沿用 Actions 的紧凑布局：名称列至少 10 格，按列表最长名称扩展、最多 24 格，过长时截断；状态紧随名称列，列间一格，不随窗口拉到最右侧。
  选中高亮只覆盖名称与状态区域。主屏每行只有名称和状态。页脚左侧显示选中服务的路径和 enabled/temporary 类型；截断路径时保留完整类型。
- ↑/↓ 或 j/k 移动。刷新按服务名保持选择；服务消失时选择最近行，并退出针对旧服务的操作页。
- Enter 打开无框操作页，初始选中 Attach。菜单顺序为 Attach、Start、Stop、Restart、Edit、History、Disable。
  菜单正文有七个动作；标题下的原空行显示弱化路径，与标题左对齐，使用整个工作区宽度；保留 ~ 缩写，过长时从左省略且不换行。底部路径、类型和反馈保留，菜单位置不变。
  ↑/↓、j/k 移动，Enter 执行；PgUp/PgDn 按页移动选择，Home/End 选择首项/末项，选中项始终可见。
  `?` 帮助优先显示当前页按键；名称超过 24 格或路径超过 40 格时，在按键后补充完整名称、路径和类型，关闭后恢复动作选择。
- a/s/x/r/e/h/d 是上述动作的直接快捷键。主屏只显示 Enter、? 和 Esc/q；所有动作可通过可见菜单找到。
- Disable 先显示确认页，正文完整显示 `Stops and unregisters service.`，下方紧接 Cancel/Disable，默认 Cancel。其他生命周期动作直接执行。
  Esc/q 取消并返回原入口；Start、Stop、Restart 沿用现有后端语义。
- 操作进行中显示进度，允许导航和帮助，禁止再提交动作。主屏退出或 Ctrl+C 请求等待操作完成；
  成功后退出，失败后留下完整错误。子页面 Esc/q 返回上一级。
- 进度、成功消息和断线提示替换页脚左侧信息，右侧按键仍按当前页面对齐；成功消息保留三秒；错误显示可滚动阅读页，Esc/q 关闭后回到原位置，不自动重试。
- 首次列表查询未返回时，仅显示 served 标题和 `? help   esc/q quit`，内容区、数量和详情留空；成功后才显示列表或空列表提示，实际失败或两秒超时后才显示不可用与重试。后续刷新保留已有内容，不重新进入首次加载状态。
- manager 断连后保留旧列表并标记 stale，禁止执行服务动作；有服务时保留 Enter 菜单入口，可查看信息，断线和恢复不改变页脚行数；后台持续重连，列表查询两秒无响应即标记不可用，导航和退出不等待查询。? 帮助显示完整连接错误。
- 空列表显示 served enable 和 served run 的使用提示，不显示空表格或随机 tips。

## 历史、帮助与返回

- 历史列表按紧凑列显示记录名、字节数和 disk/memory，记录名最多 24 格，空间不足时优先截断记录名；页脚左侧显示选中记录 ID。Enter 打开，Esc/q 返回。
- 历史内容显示清理后的文本和逻辑行位置 current/total。↑/↓、j/k 按逻辑行移动，
  PgUp/PgDn 按正文高度移动，g/Home 到开头，G/End 到末尾。视觉换行不增加逻辑行数。
- 帮助正文的按键使用青色并对齐，说明使用默认色；窄窗口按说明列宽换行。主界面、Actions 和确认页只列当前页面导航、执行、返回及 Ctrl+C，不重复动作快捷键和 attach 通用说明；操作中和断线时追加对应状态。
- 英文 `?` 和输入法提交的全角 `？` 等效，均可打开或关闭当前页帮助（包括历史列表和内容页）；页脚仍显示 `?`。
- ? 显示当前页面的帮助；Esc/q/? 关闭并保留选中项与滚动位置。
- 普通阅读页和日志页在需要滚动时于页脚左侧显示当前位置；帮助及配置确认页在提示行右侧显示位置，全部内容可见时留空。
- 帮助和错误正文按终端宽度换行，可用 ↑/↓、j/k、PgUp/PgDn、Home/End、g/G 阅读。
- Attach 的原始输入、第二屏、Ctrl+C detach 和崩溃诊断保持原有语义。返回后重绘原菜单或列表。
  崩溃日志确认使用无框阅读页，Enter/y 打开编辑器，n/Esc/q 取消。
- Actions 的 Edit 与独立 served edit 共用表单；按注册配置路径打开，不按工作目录猜测。临时服务保留灰色不可用 Edit，触发时说明原因；退出编辑恢复原菜单，主列表直接 e 编辑后返回该服务的 Actions。

## 验收

- 管理页验证空列表及 1/6/7/8/50 项、最大工作区宽度、跟随正文的页脚，以及阅读页的底部固定页脚。
- TestBackend 覆盖 40×10、80×24、120×40、缩放、长中文名称、组合字符、长路径和多页列表。
- 页脚验证一行/两行切换边界、按页面类型对齐、按键完整、样式区分、反馈期间位置稳定，以及正文高度与翻页一致。
- 按键测试覆盖菜单动作、帮助返回、默认取消、禁用确认、错误阅读、断连保护、选择身份与异步操作限制。
- 真正的 PTY 流程验证 attach 返回、历史和帮助切换、菜单执行以及恢复终端。
- 预览导出实际前景色、背景色及文字修饰，分别检查深色、浅色和 `NO_COLOR`。
- 终端默认底色不得被覆盖；深浅背景和低色彩环境均须保持内容与选择可识别。
- 修改后运行 make check、make docs-check；手册和 README 必须与操作目录一致。

## 配置表单

- Basic、Runtime、Logs、Environment 四页；字段采用文本、开关、枚举和键值列表，不展示 JSON5 源码。
- 沿用默认底色、青色强调、反色选择和无外框布局；浏览工作区最大 76 列，编辑页使用可用终端宽度；总览和字段编辑页底部细线分隔提示。
- 编辑总览和普通字段使用主屏的默认高度，横线及页脚末行对齐。从 Actions 进入时继承项目数量基准，独立 `served edit` 使用共同最小基准，不查询 manager。页签切换不改变高度，空间不足时压缩字段间空行并滚动。
- 命令和单个变量表单按实际折行数增高，短内容保持默认高度；到终端上限后滚动，内容删除后收拢。Environment 总览保持默认高度。
- 小于 60 列的正文采用标签和值上下排列；最小窗口 40×10，选中字段跟随滚动。编辑标题优先保留 modified，空间不足时截短字段名称。
- Enter 编辑或完成输入，Esc 返回并保留草稿；Tab／Shift+Tab 不切换焦点。
- 命令和环境变量值使用 Shift+Enter 换行，Ctrl+J 作为兼容后备；线下仅保留必要操作，详细键位放入主动打开的帮助。
- 无效输入保留为独立草稿，保存时定位错误；环境变量键和值作为一次完整修改处理。
- 校验错误在底部分隔线上方换行，最多三行；超过三行或会挤掉当前字段必要内容时打开可滚动错误页。返回后保留草稿、焦点和一行错误摘要，再次保存重新展示完整错误。
- 浏览页上下键只在正文移动；移除切换、Enter 执行、左右切页和重命名提示，主页面不提供焦点按钮。确认页方向键选择、Enter 确认，默认继续编辑或取消。
- 配置确认页使用独立标题、路径、后果说明和选项，不显示页签；按实际正文高度收拢，选项下空一行放左对齐提示。长说明用 PgUp/PgDn、Home/End 滚动，选项保持可见。
- Ctrl+S 仅在配置主页面执行保存和校验，字段编辑中不写入文件；Ctrl+Q 退出时确认未保存改动，Enter 默认取消。Ctrl+R 重载也须确认。
- PTY 关闭时禁用终端尺寸同步，持久化关闭时禁用日志限制；保留原值。
- JSON5 按属性局部修改，保留注释、未改字段、CRLF 和权限；拒绝覆盖外部修改。
- 不支持的源码交给显式 --editor；保存本身不改变服务运行状态；后续确认的 Restart 单独执行。
- 命令和环境变量值按字形宽度自动折行，不修改原文；上下键按显示行移动，PgUp／PgDn 按视口高度移动。
- 内容超出可视高度时显示右侧滚动条，光标和滚动位置在缩放后保持可见。
- 环境变量名称和值同屏；名称按下进入值，值首个显示行按上返回名称。
- Environment 总览固定名称一行、值一行；按完整条目滚动，长值截断，不再展示 Overrides 说明。
- 已有变量的编辑表单内提供 Delete 按钮；值末行按下进入，按钮按上返回值，Enter 请求确认，默认 Cancel。列表 d 不再删除。
- 删除绑定原条目身份；取消保留输入，确认只修改草稿，保存后才写入文件。
- 命令和变量值用 ANSI 242 灰色显示空格 ·、Tab →···、LF ↵、CRLF ␍↵，与正文样式的字面量标记字符区分；选中时只改变标记文字颜色，保留反色背景。NO_COLOR 下使用 DIM。软换行不加标记。
- 线下仅显示必要操作：总览 `ctrl+s save · esc quit · ? help`，Environment 另加 `a add`；字段编辑页、帮助和错误阅读页仅 `esc back`；确认页 `enter confirm · esc back`。不显示字段说明或状态；必要错误在正文显示，保存成功只通过 modified 消失体现。
- 配置帮助复用主页／Actions 的独立阅读页和青色按键列，仅显示当前总览、字段或环境变量焦点的操作；隐藏配置路径和页签，保留 `esc back`。关闭后恢复草稿、焦点、光标和编辑滚动位置；窄屏帮助可滚动。

- 新建配置模板显式使用 on-failure 和 persist_logs true；不迁移旧文件，不改变省略字段的默认值或临时服务默认值。
- 有头表单成功写入实际修改后，按规范化配置路径匹配服务；面板入口额外绑定原服务名。running/starting/restarting 状态询问 Not now／Restart，默认 Not now，Esc 同义；停止服务及无变化保存不询问。
- Ctrl+S 的重启询问结束后留在表单；Save and exit 完成询问后退出。manager 查询两秒超时，无法检查时说明配置已保存；重启前再次核对身份和运行状态，失败保留已保存文件并回到编辑器错误页。
- 重启执行期间显示进度并禁止重复提交；改名不自动重新注册。外部编辑器、无头版和非交互调用不增加重启询问。
