# served TUI 设计规范

状态：已定型。新页面必须复用本规范的模板和组件；确需新交互时，先更新规范和验收案例。
本规范取代旧版常驻 tips 和多行完整快捷键栏。它只约束管理界面；attach 交给服务原始终端。

## 视觉规则

- 默认无框。禁止装饰边框、阴影、渐变、emoji、图标字体和装饰动画。
- 使用终端默认前景和背景，不提供主题选择。标题加粗，辅助文字弱化；选中行反色并保留 `>`。
- running/stopped 使用默认文字，starting/restarting 使用 ANSI 黄色，failed 使用 ANSI 红色。
  状态必须有文字。终端不显示颜色时，选择和状态仍能识别。
- 宽度至少 80 列时左右各留两格，40–79 列时各留一格；上下各留一行。
- 页面顺序固定为标题、空行、正文、空行、合并页脚。
  正文占满余高；不添加侧栏，不因屏幕变宽增加信息。
- 页脚信息靠左，按键组整体靠右；按键使用默认前景色，说明和左侧信息弱化。
  按键与说明间隔一格，按键组之间三格，左右信息至少间隔两格。
- 扣除按键组和两格间隔后，左侧至少可容纳 20 格时共用一行；否则使用相邻两行，
  上行信息、下行右对齐按键，不插入空行。切换只取决于窗口宽度和当前页按键组。
  正文高度、翻页和缩放后的滚动校正使用同一布局计算。
- 最小可用尺寸为 40×10。更小时只显示扩大窗口提示，Esc/q 和 Ctrl+C 仍可返回或退出。
- 名称和路径按字符单元宽度截断，保留完整字素。名称保留开头，路径保留末尾，用 `…` 标记。
  路径在 HOME 内时显示 `~`。完整名称、路径和类型可在操作页的 `?` 帮助中查看，PgUp/PgDn 滚动。

## 需求到模板的映射

| 需求 | 模板 | 允许的业务输入 |
| --- | --- | --- |
| 选择服务或历史记录 | 列表 | 标题、计数、行、选中项详情 |
| 对一个服务执行动作 | 操作页 | 服务信息、统一动作目录 |
| 阅读帮助或错误 | 阅读页 | 标题、完整正文 |
| 阅读输出历史 | 日志页 | 记录、逻辑行位置、加载状态 |
| 确认禁用 | 确认页 | 服务名称、后果说明、取消/禁用 |

页面骨架、列表选择、状态样式、文本截断和阅读滚动由共享组件处理。
业务页面不得自行选择颜色、边框或布局。动作目录统一生成菜单、快捷键和动作帮助。

## 主屏与操作

```text
 served                              3 services

 > api                               running
   worker                            running
   scheduler                         stopped

 ~/projects/api · enabled                 enter actions   ? help   q quit
```

- 主屏每行只有名称和状态。页脚左侧显示选中服务的路径和 enabled/temporary 类型；截断路径时保留完整类型。
- ↑/↓ 或 j/k 移动。刷新按服务名保持选择；服务消失时选择最近行，并退出针对旧服务的操作页。
- Enter 打开无框操作页，初始选中 Attach。菜单顺序为 Attach、Start、Stop、Restart、History、Disable。
  菜单正文只有六个动作；路径和类型放在页脚左侧，反馈只在页脚显示。
  ↑/↓、j/k 移动，Enter 执行；PgUp/PgDn 按页移动选择，Home/End 选择首项/末项，选中项始终可见。
  `?` 帮助先显示完整服务名称、路径和类型，关闭后恢复动作选择。
- a/s/x/r/h/d 是上述动作的直接快捷键。主屏只显示 Enter、? 和 q；所有动作可通过可见菜单找到。
- Disable 先显示确认页，正文完整显示 `Stops and unregisters service.`，下方紧接 Cancel/Disable，默认 Cancel。其他生命周期动作直接执行。
  Esc/q 取消并返回原入口；Start、Stop、Restart 沿用现有后端语义。
- 操作进行中显示进度，允许导航和帮助，禁止再提交动作。主屏退出或 Ctrl+C 请求等待操作完成；
  成功后退出，失败后留下完整错误。子页面 Esc/q 返回上一级。
- 进度、成功消息和断线提示替换页脚左侧信息，右侧按键仍按当前页面对齐；成功消息保留三秒；错误显示可滚动阅读页，Esc/q 关闭后回到原位置，不自动重试。
- manager 断连后保留旧列表并标记 stale，禁止执行服务动作；有服务时保留 Enter 菜单入口，可查看信息，断线和恢复不改变页脚行数；后台持续重连，列表查询两秒无响应即标记不可用，导航和退出不等待查询。? 帮助显示完整连接错误。
- 空列表显示 served enable 和 served run 的使用提示，不显示空表格或随机 tips。

## 历史、帮助与返回

- 历史列表显示记录名、字节数和 disk/memory；页脚左侧显示选中记录 ID。Enter 打开，Esc/q 返回。
- 历史内容显示清理后的文本和逻辑行位置 current/total。↑/↓、j/k 按逻辑行移动，
  PgUp/PgDn 按正文高度移动，g/Home 到开头，G/End 到末尾。视觉换行不增加逻辑行数。
- ? 显示当前页面的帮助；Esc/q/? 关闭并保留选中项与滚动位置。
- 阅读页和日志页在需要滚动时于页脚左侧显示当前位置，全部内容可见时留空。
- 帮助和错误正文按终端宽度换行，可用 ↑/↓、j/k、PgUp/PgDn、Home/End、g/G 阅读。
- Attach 的原始输入、第二屏、Ctrl+C detach 和崩溃诊断保持原有语义。返回后重绘原菜单或列表。
  崩溃日志确认使用无框阅读页，Enter/y 打开编辑器，n/Esc/q 取消。
- 配置仍通过 served edit 编辑，不新增搜索、鼠标操作或 TUI 编辑器。

## 验收

- TestBackend 覆盖 40×10、80×24、120×40、缩放、长中文名称、组合字符、长路径和多页列表。
- 页脚验证一行/两行切换边界、按键完整与右对齐、样式区分、反馈期间位置稳定，以及正文高度与翻页一致。
- 按键测试覆盖菜单动作、帮助返回、默认取消、禁用确认、错误阅读、断连保护、选择身份与异步操作限制。
- 真正的 PTY 流程验证 attach 返回、历史和帮助切换、菜单执行以及恢复终端。
- 终端默认底色不得被覆盖；深浅背景和低色彩环境均须保持内容与选择可识别。
- 修改后运行 make check、make docs-check；手册和 README 必须与操作目录一致。
